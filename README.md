# Estructuras de datos en Python

Repositorio donde practico las estructuras de datos que vemos en clase.
Cada archivo tiene la clase y un ejemplo de uso al final.

## Estructuras

### Lineales
- **Pila** (`lineales/pila.py`): el ultimo en entrar es el primero en salir
- **Cola** (`lineales/cola.py`): el primero en entrar es el primero en salir
- **Lista enlazada** (`lineales/lista_enlazada.py`): nodos conectados uno tras otro

### No lineales
- **Arbol binario de busqueda** (`no_lineales/arbol_binario.py`)
- **Grafo** (`no_lineales/grafo.py`): con lista de adyacencia y recorrido BFS

## Como ejecutarlo

Tener Python 3 instalado y en la terminal:

    python main.py

O probar cada estructura por separado:

    python lineales/pila.py
